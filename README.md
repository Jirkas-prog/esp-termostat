# ESP termostat

Experimentální redundantní termostat: dvě jednotky, DS18B20, UART a Wi-Fi/MQTT nebo Zigbee.

## Sestavení a nastavení

ESP-IDF 5.3.1; profily jsou ve firmware/sdkconfig.defaults*. Host testy: tools/test.ps1. Jde o vývojovou verzi pro ověření na stole, nikoli certifikovanou ochranu topného systému. Před připojením výkonové části ověřte elektrické zapojení a nezávislé ochrany.

## Obsah repozitáře

Zdrojové kódy, konfigurace sestavení a dostupné testy. Soukromé přístupy, záznamy instalací, zálohy zařízení a dříve sestavené binární soubory sem nepatří. Příklady vyplňte vlastními údaji až místně.

Toto je zdrojový snímek uložený 1. 11. 2026. Stav konkrétních kontrol je uveden v `VALIDATION.md`; nahrání zdrojů neznamená nové ověření na fyzickém zařízení.
